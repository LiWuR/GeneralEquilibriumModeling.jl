GEM.AuxiliaryEquationsV4

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4 — Module
AuxiliaryEquationsV4

Define scalar model-level equations paired with auxiliary MCP variables and evaluate them from explicitly declared equilibrium observations.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.AuxiliaryEquation — Type
AuxiliaryEquation(name, paired_variable, equation_function;
                  observed_variables=[])

Define a scalar equilibrium equation paired with one auxiliary variable. equation_function receives the values of observed_variables in their declared order and must return one scalar value.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_function — Method
auxiliary_equation_function(equation)

Return the function defining an auxiliary equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_name — Method
auxiliary_equation_name(equation)

Return the symbolic name of an auxiliary equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_observed_variable_count — Method
auxiliary_equation_observed_variable_count(equation)

Return the number of variables observed by an auxiliary equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_observed_variables — Method
auxiliary_equation_observed_variables(equation)

Return a copy of the variable references observed by an equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_paired_variable — Method
auxiliary_equation_paired_variable(equation)

Return the auxiliary-variable reference paired with an equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_paired_variable_name — Method
auxiliary_equation_paired_variable_name(equation)

Return the name of the auxiliary variable paired with an equation.

GeneralEquilibriumModeling.GEM.AuxiliaryEquationsV4.auxiliary_equation_value — Method
auxiliary_equation_value(equation, observed_values)

Evaluate equation from values supplied in the order of its declared observed-variable references.
