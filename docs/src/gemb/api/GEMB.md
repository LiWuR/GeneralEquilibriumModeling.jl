# GEMB

`GEMB` is the high-level model-building layer built on top of `GEM`.

## Loading

```julia
using GeneralEquilibriumModeling.GEMB
```

## Public API organization

Unlike `GEM`, the ordinary GEMB implementation files are included directly into the single `GeneralEquilibriumModeling.GEMB` module. The API documentation is therefore divided by functional source group rather than by child module.

See the [API index](../api.md) for the detailed public API pages.
